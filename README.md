# pour
Print ASCII art of your choice

## Usage

Make sure to drop your files in .config/pour
```sh
pour -a, --available          # Shows all available files in .config/pour
pour -p, --print <FILENAME>   # Prints the desired file 
pour -r, --random             # Picks and prints a random file from .config/pour
```

## Note

The terminal gets automatically cleared before anything gets printed.\
This was made for Linux.
